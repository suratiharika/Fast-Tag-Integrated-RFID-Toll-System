# Fast-Tag-Integrated-RFID-Toll-System
FAST-TAG Integrated RFID Toll System is an Embedded C-based automated toll collection system using LPC2148 ARM7, RFID, UART, I2C EEPROM, LCD, keypad, GP2D12 distance sensor, and DC motor. It automates vehicle identification, toll balance deduction, and gate opening/closing.
